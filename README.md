# MILUNA — ミルナ公式サイト

銀河（ミルキーウェイ）と月（ルナ）から名付けられた黒猫のファーキャラクター、ミルナの公式サイト。

「キャラクターの写真集 × インディーズアーティストの公式サイト × 少し不思議な夜の世界」をコンセプトにしたエディトリアルデザイン。写真・タイポグラフィ・余白でミルナの世界観を伝える構成で、一般的なAI生成サイトにありがちなグラデーション背景・Glassmorphism・3カラムカードなどは使用していない。

## キャラクター情報

- **名前**: ミルナ (Miluna)
- **性別**: 男の子
- **種族**: 黒猫（ファーキャラクター）
- **名前の由来**: ミルキーウェイ（銀河）+ ルナ（月）
- **特徴**: 額の紫色のストライプ／白と黒の大きな耳／ブルーの瞳／ダークグレー×ブラックの毛並み／思慮深く遊び心のある性格

## ページ構成

| ファイル | 内容 |
|---|---|
| `index.html` | HERO / ABOUT / PHOTO DIARY（抜粋） / WORLD / CONTACT |
| `gallery.html` | PHOTO DIARY 全編。フルブリード写真（PLATE）と可変サイズのマソンリーグリッドを交互に配置 |
| `story.html` | 誕生秘話と「ミルナの一日」のエディトリアルなタイムライン |
| `events.html` | 参加イベントの記録一覧 |

## デザインシステム

**カラー**（ミルナ自身の配色から抽出。紫はアクセントのみで背景には使わない）

```css
--base:    #0B0D10; /* ほぼ黒の背景 */
--surface: #171A1F; /* チャコールグレー */
--text:    #EEEDE8; /* 暖かみのあるオフホワイト */
--blue:    #7CB7D8; /* 瞳の色（リンク・強調） */
--purple:  #7455A6; /* 額のストライプ（番号・下線などの小さなアクセント） */
```

**タイポグラフィ**: 英字見出しは Archivo（Bold〜Black）、日本語本文は Noto Sans JP。見出しは基本左揃えで、あえて位置をずらす。

**レイアウト**: 大胆な写真＋余白を基本にした非対称エディトリアルグリッド。角丸はほぼ使わない。

## 実装メモ

- `css/style.css` … デザインシステム全体（1ファイル、ページ共通）
- `js/main.js` … ヘッダーの縮小、スムーススクロール、reveal-on-scroll、ギャラリーのライトボックス（ピンチズーム対応）とフィルター、イベント一覧の描画、イースターエッグ
- `data/events.json` … イベント一覧のデータソース（`events.html` が fetch、失敗時は `main.js` 内のフォールバックデータを使用）
- 画像は `img/<撮影者名>/` ごとに配置。`gallery.html` のキャプションは撮影者クレジット主体（未キャプションの写真は `FRAME 0xx` として連番表示）

### イースターエッグ（控えめな実装。常時は動かさない）

- カーソルを数秒動かし続けると、足跡が1〜2個だけ現れて消える
- ロゴ（左上の「MILUNA」）を5回クリックすると、ミルナが画面下を一度だけ歩いて通り過ぎる
- 画面をダブルクリックすると小さな星座が描かれ、数秒で消える
- キーボードで「miluna」とタイプすると、静かなメッセージが一瞬だけ表示される
